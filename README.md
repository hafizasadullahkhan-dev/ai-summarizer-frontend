# AI Text Summarizer - Frontend

A modern, responsive, and highly interactive React application that turns long articles and text into concise summaries using the power of AI.

## ✨ Features
- **Clean UI/UX:** Dark mode with glassmorphism effects, smooth animations, and gradient text.
- **Fully Responsive:** Works perfectly on mobile, tablet, and desktop devices.
- **Smart Form Handling:** Real-time character counting (max 10,000), input validation, and form submission via the "Enter" key.
- **Interactive Controls:** Try an example text with one click, clear results instantly, and copy summaries to the clipboard.
- **Error Handling:** Graceful error messages for timeouts and server issues.
- **Accessibility:** Built with semantic HTML and `aria-live` regions for screen readers.

## 🛠️ Tech Stack
- **React.js** (v19) - Frontend library
- **CSS3** - Custom styling, animations, and media queries (No heavy UI libraries needed)
- **Testing Library** - For unit testing components
